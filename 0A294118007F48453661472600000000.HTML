Programm /VWK/EAI_DL_DISTRIBUTION
XI Verteilung von SKS Verteilerlisten

Verwendung

Dieser Report dient der parallelen Massendatenverteilung von Geschäftspartnern und/oder Beziehungen. Er wird in der Regel von der EAI Jobcontrol gestartet.

Funktionsumfang

Selektion

  • Geschäftspartnernummern: Der Report kann ausschliesslich eine Liste von einzelnen Geschäftspartnernummern (inkludierend) verarbeiten (Select Options Include, Equals).
  • XI Package Size: Anzahl von Geschäftspartnern in einer XI Nachricht. (Vorschlagswert 50). Es werden alle Beziehungen der in XI Package Size angegebenen Geschäftspartner in einer Nachricht versand.
  • Parameterstring: Der Parameterstring erwartet die Parameter durch Simikolon getrennt. Folgende Parameter sind zugelassen:
    • Verteilung: BUPA (Es werden nur Geschäftspartner verteilt), RELA (Es werden nur Beziehungen verteilt), BURE (Es werden Geschäftspartner und Beziehungen verteilt)
    • Exception Mode: Der Exception Mode wird an die Serialisierung durchgereicht.
